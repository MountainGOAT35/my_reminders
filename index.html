Backup and restore

App data is stored only in this browser on this device. Export a backup before clearing browser data or switching devices. The app creates backup files locally in your browser and does not upload them to GitHub or any server. On iPhone, use Save/share backup if normal downloads do not appear in Files.

This handle is included in exported backups so another device can group imported reminders by source. It is not an account, login, or cloud sync feature.
